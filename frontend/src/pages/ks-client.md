**KS Client** is a performance and visual resource pack for **Minecraft Bedrock Edition**, built by **KS Warrior**. It is designed to reduce lag, sharpen the interface and add 3D detail without mods, launchers or extra apps.

## Why KS Client?

- **Smoother gameplay** — tuned for better Minecraft performance and less lag
- **3D models** — Mace, shield front and side, bow, crossbow and player-skin totem
- **Modern interface** — a new UI with armor, offhand, health and durability information
- **Cleaner visuals** — bright textures, clear water and a low fire effect for visibility
- **Simple setup** — one `.mcpack` file, imported and enabled in Minecraft

## Install

1. Download the latest `.mcpack` from this page.
2. Open the file with Minecraft Bedrock Edition.
3. Enable **KS Client** in **Settings → Global Resources → Resource Packs**.
4. Restart your world and enjoy the new look.
