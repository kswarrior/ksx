1. Install Node.js

sudo apt update && \
sudo apt install curl -y && \
curl -fsSL https://deb.nodesource.com/setup_current.x | sudo -E bash - && \
sudo apt install nodejs -y

2. Create project folder

mkdir mc-bot
cd mc-bot
npm init -y

Bot Features & Commands (say in chat, only owner can use)

  • !follow <name> - Bot follows you
  • !come - Bot comes to your position
  • !guard - Bot guards & protects you (follows + auto-attacks threats)
  • !stopguard - Stop protecting you
  • !stop - Stop current action
  • !attack <player> - Attack a specific player
  • !huntmobs - Hunt and kill nearby hostile mobs
  • !pvpstop - Stop PVP/hunting
  • !mine <block> - Mine specified block (e.g., !mine diamond_ore)
  • !equip - Re-equip best armor, weapons, tools
  • !give <item> - Give item to owner
  • !place <item> - Place block in front of bot
  • !totem - Equip totem in offhand
  • !help - List all commands
  • Auto-equip armor, sword/axe, shield/totem based on situation
  • Auto-eat when hungry/low health
  • Auto-respawn on death
