MC Server Without Hosting

By KS Warrior - Updated with Latest Java 25 and Minecraft Server 1.21.11

MC Server in CodeSandbox

Update System & Install wget (if needed)

apt update -y && apt upgrade -y && apt install wget -y

Install Latest Java (Oracle JDK 25) via URL

wget https://download.oracle.com/java/25/latest/jdk-25_linux-x64_bin.tar.gz
tar -xvf jdk-25_linux-x64_bin.tar.gz
export JAVA_HOME=$(pwd)/jdk-25.0.2
export PATH=$JAVA_HOME/bin:$PATH
java -version

Download Minecraft Server - Enter URL below (default latest)


    
  


  
  

    
Accept Minecraft EULA

    
echo "eula=true" > eula.txt

    
  


  
  

    
Install playit.gg Plugin

    
mkdir plugins && cd plugins && wget https://github.com/playit-cloud/playit-minecraft-plugin/releases/latest/download/playit-minecraft-plugin.jar

    
  


  
  

    
Start Server - Enter RAM in MB (default 1024)
