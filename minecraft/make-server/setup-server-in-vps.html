MC Server Without Hosting

By KS Warrior

MC Server in CodeSandbox

Install Java & server

wget https://github.com/ks-warrior/MC-Server-without-hosting/releases/download/Codesandbox.io/ks-install.sh && bash ks-install.sh

Install playit.gg plugin

cd ks-server && mkdir plugins && cd plugins && wget https://github.com/playit-cloud/playit-minecraft-plugin/releases/latest/download/playit-minecraft-plugin.jar

Start server

bash ks-start.sh
